# 🌎 ECOFIE — Decisiones que cuidan el planeta

ECOFIE es un videojuego educativo donde el jugador enfrenta situaciones ambientales y elige la opción que ayude a cuidar el planeta. Cada decisión muestra sus consecuencias y puede modificar la puntuación.

## Objetivo
Promover la conciencia ambiental mediante decisiones sobre contaminación, ahorro de agua, reciclaje y protección de la naturaleza.

## ¿Cómo funciona?
1. El jugador inicia una partida.
2. El juego presenta una situación ambiental.
3. El jugador elige entre varias opciones.
4. ECOFIE explica las consecuencias y actualiza la puntuación.
5. El jugador continúa y al final consulta sus resultados.
